# Ceník import

Nahrajte export z účetního systému jako `data/cenik.xlsx` (preferované).
Pokud chcete soubor ponechat v kořeni webu, stránka načte i `cenik.xlsx`.

Stránka `cenik.html` tento soubor načítá a automaticky z něj vygeneruje tabulku.
Stačí tedy pouze vyměnit soubor `cenik.xlsx` a obsah ceníku se aktualizuje.
